Explain like I'm a junior one year into whatever field this topic belongs to, right in the chat, using big ASCII diagrams and few words.

Split the picture into several small boxes, one per stage, and let the flow run between them. Everything drawn inside a box stays English so the ASCII holds its alignment. The prose goes in the user's language as marginalia: past the box's right border, on the same line as the piece it explains, so the whole thing reads like annotated code. Every line carrying a decision, a branch, a cost, or a surprise earns a margin note.
